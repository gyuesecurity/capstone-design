# 기존 웹 버전

현재 실행되는 웹 화면을 기능별로 정리했습니다. 화면을 수정할 때는 해당 기능 폴더를 열고, 서버를 실행할 때는 [프로젝트 루트의 실행 안내](../../README.md)를 따르세요.

| 폴더 | 들어 있는 화면과 파일 |
| --- | --- |
| [홈](home/) | 로그인 전 서비스 소개, 로그인 후 서비스 홈 |
| [대시보드](dashboard/) | 증거 현황, 최근 등록 및 활동 |
| [로그인·회원가입](auth/) | 로그인, 회원가입, 약관 동의, 인증 화면 자산 |
| [내 계정](account/) | 마이페이지, 프로필 수정, 비밀번호 변경, 로그아웃 |
| [증거 등록](evidence-collection/) | 등록 유형 선택, 파일·이미지·영상·URL 등록과 완료 화면 |
| [증거 관리](evidence-management/) | 증거 목록, 검색, 필터, 상세 조회 |
| [무결성 검증](verification/) | 검증 대상 선택, 실행, 결과와 이력 |
| [보고서](reports/) | 증거 선택, 내용 작성, 미리보기, PDF, 패키지 |
| [공통 파일](shared/) | 여러 화면에서 쓰는 스타일, 화면 이동, 증거 데이터 처리 |

기존 버전의 [Netlify 시연 ZIP](../../deploy/netlify-demo.zip)과 [무결성 검증 예제](../../demo/integrity/)도 사용할 수 있습니다.
