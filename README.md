# capstone-design
2026 Capstone Design Project

## 로그인 및 회원가입 화면

- `login.html`: 로그인 화면, 회원가입 이동, 계정 찾기 안내
- `signup.html`: 회원가입 입력 및 비밀번호 조건·일치 확인
- `signup_terms.html`: 필수/선택 약관 동의 및 로그인 화면 이동

Figma 원본: https://www.figma.com/design/KTur9ZdEVI0DtyJmqPagru
로그인 `10:363`, 회원가입 `11:831`, 약관 동의 `25:4`를 구현했습니다.

현재 정적 화면 시연용입니다. 로그인 제출은 서비스 홈으로 이동하며,
회원가입 제출은 약관 동의를 거쳐 로그인 화면으로 돌아갑니다.
계정 생성, 이메일 인증, 계정 찾기는 인증 서버 연결이 필요합니다.
입력한 이름·이메일·비밀번호·인증번호는 저장하거나 서버로 전송하지 않습니다.
약관 펼침 내용은 시연 안내이며 실제 운영 약관은 별도로 제공해야 합니다.

아이콘은 `assets/auth/`에 저장한 Figma 원본 SVG를 사용합니다.
DM Sans는 동봉된 OFL 라이선스로 제공됩니다.
